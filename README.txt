# WebGIS Sidomoyo — Final Modern v9

Paket WebGIS Sidomoyo ini berisi antarmuka utama, peta interaktif, data layer, library JavaScript, legenda, dan tile orthophoto.

## Pembaruan v9
- Tata letak ponsel diperbaiki agar peta mengisi ruang layar yang tersedia, tanpa ruang kosong besar di bawahnya.
- Header mobile tetap ringkas dan panel informasi tetap dapat dibuka sebagai panel geser.
- Watermark proyek, kontrol basemap, skala, dan atribusi diatur agar tidak saling bertumpuk pada layar kecil.
- Ukuran peta Leaflet diperbarui saat orientasi atau ukuran viewport berubah.
- Popup setiap layer menggunakan desain kartu yang lebih rapi.
- Nama layer tampil di bagian paling atas.
- Informasi utama dibuat lebih besar dan menonjol.
- Atribut ditampilkan sebagai baris label dan nilai yang lebih mudah dibaca.
- Field teknis yang tidak diperlukan disembunyikan dari popup.
- Popup tidak langsung tertutup ketika pointer meninggalkan fitur.
- Pencarian NIB, filter, pengaturan layer, basemap, dan orthophoto dari versi sebelumnya dipertahankan.

## Menjalankan secara lokal
Buka `index.html` di browser. Jika browser membatasi pemuatan data lokal, jalankan folder ini melalui server lokal atau gunakan GitHub Pages.

## Publikasi
Unggah seluruh isi folder ke repository GitHub dengan struktur folder tetap dipertahankan. Pastikan `index.html` berada di root branch/folder yang dipilih pada pengaturan GitHub Pages.
