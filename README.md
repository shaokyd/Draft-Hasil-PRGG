# WebGIS Sidomoyo — Final Modern v9

Paket WebGIS Sidomoyo yang siap dijalankan secara lokal atau dipublikasikan melalui GitHub Pages.

## Pembaruan versi ini
- Tata letak mobile diperbaiki agar peta memenuhi area layar yang tersedia, tanpa ruang kosong besar di bawah peta.
- Header mobile tetap ringkas dan panel informasi tetap dapat dibuka sebagai panel geser.
- Kontrol basemap, watermark, skala, dan atribusi diatur agar tidak saling bertumpuk pada layar kecil.
- Ukuran peta Leaflet diperbarui saat layar berubah orientasi atau ukuran viewport.
- Popup setiap layer dirapikan dengan nama layer di bagian atas.
- Informasi utama ditampilkan sebagai judul besar dan detail atribut tersusun dalam baris label/nilai.
- Field teknis yang tidak diperlukan tidak ditampilkan pada popup.
- Popup tetap terbuka saat pointer meninggalkan fitur agar informasi lebih mudah dibaca.
- Layer data, pencarian NIB, filter, basemap, dan tile orthophoto dari versi sebelumnya dipertahankan.

## Menjalankan
Buka `index.html` di browser. Untuk publikasi, unggah seluruh isi folder ini ke repository GitHub Pages dengan struktur folder tetap dipertahankan.
